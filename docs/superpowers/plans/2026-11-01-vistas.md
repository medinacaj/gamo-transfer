# Vistas de registros Implementation Plan
> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.
**Goal:** Alternar tarjetas, tabla y lista compacta con preferencia por sección.
**Architecture:** Selector común en app.js; preferencia local independiente de datos comerciales; renderizar entidades con los mismos metadatos y acciones. Tablas existentes cambian presentación mediante CSS. Agenda reutiliza bookingTable para tabla y su agenda para tarjetas/lista.
**Tech Stack:** JavaScript, CSS, unittest y Playwright.
**Spec:** docs/superpowers/specs/2026-11-01-vistas-design.md
